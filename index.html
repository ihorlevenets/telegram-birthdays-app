Що по днях народження?

Отримай список з днів народження усіх своїх контактів, посортованих по датах протягом всього року, починаючи від сьогодні.

Для цього тобі спершу треба буде залогінитись своїм Телеграмом. Якщо що, ця сторінка напряму комунікує з сервером Телеграму, тому твої дані нікуди не потраплять і доступу до акаунту ні в кого крім тебе не буде

00Разове налаштування

У цій копії сторінки не вписані API-ключі. Отримай api_id та api_hash на my.telegram.org → API development tools і встав їх сюди (вони залишаться на цьому пристрої).

01Твій номер телефону

Вхід через твій акаунт Телеграму. Код-підтвердження прийде повідомленням у застосунок (не SMS).

02Код для входу

Телеграм щойно надіслав код у застосунок — глянь чат «Telegram». Тут цей код потрібен лише для входу в твій акаунт на цій веб-сторінці, щоб з нього витягнути всі дні народження.

03Хмарний пароль

У тебе ввімкнена двоетапна перевірка. Введи хмарний пароль — його перевіряє безпосередньо Телеграм.

Скануємо контакти…

Перевіряю профіль кожного контакту. Телеграм обмежує швидкість запитів, тому на великому списку це може зайняти кілька хвилин. Не закривай вкладку.

З’єднання…

Дні народження твоїх контактів

Дисклеймер: дні народження буде видно лише тих людей, хто додав їх собі в профіль і які додали тебе у свої контакти
