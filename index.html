Birthday Radar

See which of your Telegram contacts have birthdays coming up — sorted by how soon. Everything runs in your browser; nothing is sent anywhere else.

One-time setup

This copy of the page has no API credentials baked in. Get api_id and api_hash at my.telegram.org → API development tools, then paste them here (they stay on this device).

Step 1 · Your phone number

Sign in with your own Telegram account. Telegram will send a login code to your Telegram app (not SMS). Use international format.

Step 2 · Login code

Telegram just sent a code to your Telegram app (check the chat called “Telegram”). Enter it here. Never share this code with any person — this page uses it only to sign you in on this device.

Step 3 · Two-step verification

Your account has a cloud password (two-step verification). Enter it to finish signing in. It is checked by Telegram directly.

Scanning your contacts…

Checking each contact’s profile for a birthday. Telegram limits how fast this can go, so it may take a few minutes for large contact lists. Keep this tab open.

Connecting…

Upcoming birthdays

Privacy: this page talks only to Telegram’s own servers, using the same official API as Telegram’s web apps. Your session lives in this tab’s memory and disappears when you close it — but for tidiness, press “Log out” when you’re done, or remove the session later in Telegram → Settings → Devices. You’ll only see birthdays of contacts who added one and whose privacy settings allow you to see it.
